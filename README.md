# 🕸️ Simulador de Teia Orgânica - Homem-Aranha (Tobey Maguire)

Este é um algoritmo demonstrativo escrito em **Java** que simula o funcionamento biológico da teia de aranha do Peter Parker da trilogia clássica (interpretado por Tobey Maguire). 

Diferente de outras versões do herói que utilizam lançadores mecânicos e cartuchos de fluido, o Homem-Aranha de Tobey Maguire produz a teia organicamente em seu próprio corpo, tornando sua eficácia dependente do seu estado físico e emocional.

## 🧠 Como Funciona o Algoritmo?

O projeto utiliza os conceitos de **Programação Orientada a Objetos (POO)** para modelar os seguintes fatores:

1. **Energia Biológica (`energiaBio`):** Atributo do herói (de 0 a 100) que define a qualidade e a resistência do fluido produzido.
2. **Resistência à Tração:** Um cálculo interno baseado na energia atual. Se a energia/confiança do Peter estiver muito baixa, a teia perde a densidade e falha.
3. **Simulação de Crise (Homem-Aranha 2):** O código recria o cenário onde o herói sofre um bloqueio psicológico, fazendo com que o disparo falhe e ele caia (uma referência direta à clássica cena do filme de 2004).

## 🛠️ Tecnologias Utilizadas

*   **Linguagem:** Java (JDK 8 ou superior)
*   **Paradigma:** Orientada a Objetos (Classes, Métodos e Encapsulamento)

## 🚀 Como Executar no VS Code

1. Certifique-se de ter o **Extension Pack for Java** instalado no seu VS Code.
2. Baixe ou copie o arquivo `TeiaTobeyMaguire.java` para a sua pasta de trabalho.
3. Abra o arquivo no VS Code.
4. Clique no botão **Run** que aparece logo acima da linha do método `public static void main`.
5. O resultado da simulação será exibido diretamente no seu terminal.
